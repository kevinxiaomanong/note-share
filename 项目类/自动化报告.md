### 7、Hook

#### 7.1useRequest mutate

mutate函数是useRequest这个hook提供的 该hook旨在封装异步请求 

mutate在于手动更新请求返回的数据，这里要注意mutate不会重新发起请求

通常在以下场景使用mutate函数：

- 用户进行一些操作后 本地直接计算新的数据 并希望立即更新页面展示 
- 减少不必要的网络请求



#### 7.2 useMemo

const memoizedValue = useMemo(callback, dependencies);

 callback回调函数 用户计算需要缓存的值 

dependencies依赖项 只要依赖项里任何一个发生变化 会重新调用回调函数计算缓存值

而如果依赖项为空数组，意味着只在组件加载时计算一次

我们最后找到了为什么不能中断请求的原因：

```
export async function fetchWithTimeout(resource, options = {}, timeout = 1000 * 60 * 5) {
  const time = Number(timeout) || 1000 * 60 * 5;
  const { signal } = options;
  const controller = signal ? null : new AbortController();
  const timeoutId = setTimeout(() => {
    if (controller) controller.abort();
  }, time);

  try {
    const response = await fetch(resource, {
      ...options,
      signal: signal || (controller && controller.signal), // 使用传入的 signal 或内部创建的 signal
    });
    clearTimeout(timeoutId);
    return response;
  } catch (error) {
    clearTimeout(timeoutId);
    throw error;
  }
}
```



所以我们现在又再包了一层

如果fetchWithTimeout传入了signal 则复用该AbortController

#### css样式学习

1、position属性

用于设置元素的定位方式，后续可以通过top、right、bottom、left属性来进一步确定元素的具体位置

值：

- static 默认值 元素按照正常的文档流进行布局 top、right、bottom、left和z-index属性无效
- relative 元素相对其正常位置进行定位 top、right、bottom、left属性会使元素从其正常位置偏移
- absolute 即相对其已定位的祖先元素 进行定位 
- fixed 相对浏览器窗口进行定位 即使页面滚动 元素的位置也不变
- sticky 元素在屏幕范围内 正常布局 如果滚动到屏幕范围之外 则固定在指定位置



2、display属性

定义元素的显示类型，以及元素在页面中布局

- block 以块级元素的形式显示 会独占一行 并且可以设置宽度和高度 <div>
- inline 以行内元素的形式显示，不会独占一行，不能设置宽度和高度，由内容决定 <span>
- inline-block 行内块元素形式显式 不独占一行 但可以设置宽度和高度
- flex 弹性容器 子元素称为弹性项目 可以使用flex-direction`、`justify-content`、`align-items来控制
- grid 网格容器 子元素为网格项目 可以使用 `grid-template-columns`、`grid-template-rows` 等属性来定义网格的结构
- none 元素不展示



3、opacity

透明度

从0.0完全透明到1.0完全不透明 来控制元素可见程度



4、z-index 设置元素堆叠顺序 即元素垂直屏幕方向上的显示层次

仅仅对定位元素有效 z-index越大 越在上面



5、float

定义元素浮动方式，使元素脱离正常文档流并向左或向右浮动
