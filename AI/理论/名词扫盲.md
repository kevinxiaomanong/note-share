### 1、AI infra&大模型算法&大模型应用

**AI infra**

AI infra（AI infrastructure）指的是人工智能基础设施，可以理解为支撑大模型训练+推理+应用全生命周期的底层工程系统，核心关注以下领域：

| 子领域         | 核心问题                         |
| -------------- | -------------------------------- |
| 分布式训练框架 | 如何用千卡GPU联合训练一个模型？  |
| 模型推理服务   | 如何高并发、低延迟               |
| 模型部署与编排 | 如何在k8s上弹性调度GPU服务       |
| 向量数据库     | 如何高效存储/检索十亿级embedding |

AI infra工程师的典型职责：

1. 部署开源大模型到生产环境，用vLLM+Docker+k8s提供HTTP API
2. 优化推理性能，启用PagedAttention（vLLM特性）提升吞吐
3. 设计高可用架构、集成可观测性（日志、指标、trace链路）、网络隔离（API不出内网）、限流



技术栈：

- python、GO
- 系统：k8s、Docker、cuda、vllm
- 数据库：Milvus、qdrant、redis
- 监控：Prometheus、grafana



适合人群：系统工程师、SRE、后端工程师转型、强工程能力，懂GPU基础





**大模型算法岗**

核心目标：设计、训练、优化大模型本身--让模型更聪明、高效、专业

| 方向                 | 具体工作                                            |
| -------------------- | --------------------------------------------------- |
| 基础模型研发         | 设计新架构（如改进Transformer）、预训练千亿参数模型 |
| 模型微调（SFT/RLHF） | 在垂直领域（如金融、医疗）微调模型，提升专业性      |
| 模型压缩与加速       | 量化、剪枝、蒸馏，让大模型能在手机/边缘运行         |
| 多模态/Agent算法     | 研究图文理解、语言生产、智能体决策等前沿能力        |
| 评估与对齐           | 设计评测集、减少幻觉                                |

技术栈：

- python、C++（高性能算子）
- 框架：Pytorch、DeepSpeed

输出：产出模型权重.bin文件和训练/推理脚本，部署的Qwen、Llama来自这类团队

适合强数学+编程能力，热爱前沿研究，硕士以上



**大模型应用开发岗**

用大模型解决具体业务问题--把AI能力转化为用户价值

| 场景             | 具体工作                                      |
| ---------------- | --------------------------------------------- |
| RAG应用开发      | 构建企业知识库问答（埋点助手）、文档摘要      |
| Agent系统开发    | 开发能调用工具的智能体（自动查数据+生成报告） |
| 前端集成         | 在web/app/im 中嵌入聊天界面（如copilot）      |
| Prompt工程与评估 | 设计高质量prompt，构建评估pipeline            |

技术栈：

- 语言：python、java、typescript
- 框架：Langchain
- 后端：springboot
- 数据库：PostgreSQL
- 部署：docker、k8s、serverless



我们依赖算法岗训练的模型，也依赖AI infra，需要调用它们部署的推理服务、直接面向用户

适合：全栈/后端工程师、懂业务、重交付、强工程落地能力



**三者协作关系**

算法岗关注模型好不好，产出模型给infra，infra部署vLLM服务，提供API为大模型应用开发岗调用，关注服务稳不稳、快不快，而我们去开发具体应用落地



**转型建议**

可以先深耕应用开发，打造标杆项目，逐步了解infra
