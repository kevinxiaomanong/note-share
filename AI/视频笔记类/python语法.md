### 装饰器

本质是一个接受函数作为参数并返回函数的高阶函数，可以在不修改原函数代码的情况下为其增加额外功能，这本身也是一种设计模式



正好在搓重试装饰器的时候有一个这种写法：

```
def wrapper(*args, **kwargs):
```

查了下args表示位置参数（1,2），kwargs表示关键字参数（a=1,b=1）





### 上下文管理器

确保某些代码在特定的上下文中运行，并在退出该上下文时自动执行清理工作，它实现了两个特殊方法：

- __enter__()：进入上下文时调用
- exit（）：退出上下文时调用



### 模块导入&包管理

Conda是一个包和环境管理的工具，可以快速安装、运行和更新包和相关依赖，也可以轻易地创建、保存、加载和转换环境，miniconda是anaconda的轻量级替代，默认只包含conda python和依赖包，anaconda是科学计算的python发行版，但会预先安装许多常用的python套件占用较多磁盘



为什么需要conda？

一个典型python项目会使用多个包来完成功能，其中一些包也可能被其他项目所使用，而项目之间共享的包可能会引起冲突，解决方法就是虚拟环境，每个项目创建一个独立的虚拟环境来隔离包冲突，常见的python虚拟环境管理工具有：

- virtualenv
- conda
- venv
