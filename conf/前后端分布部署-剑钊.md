### 准备工作：

1. 前端修改base publicpath路径为/web 且配置为history.type=browser
2. 后端默认将域名根目录重定向到/web 

```
@RestController
public class IndexController {
    @RequestMapping("/")
    public void index(HttpServletResponse response) throws IOException {
//    redirect to frontend app deploy path
        response.sendRedirect("/web");
    }

}
```

3、前端需要验证登录态 未登录重定向到后端域名根目录

4、前端部署有两种方式 pm2 start ./index.js\ 和 serve ./dist --spa\ 主要还是看你有没有index.js

然后前后端的域名保持一致 通过path来区分
